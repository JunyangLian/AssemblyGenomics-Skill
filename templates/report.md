# 组装阶段汇总报告模板

本文件定义 `scripts/summarize_results.py` 生成的 Markdown 报告的结构契约。
实际报告由该脚本确定性生成，数字一律取自结构化产物，缺失/失败/不适用如实标注。

## 结构

- 交付表示：`{representation}`（primary_reference / subgenome_resolved / ...）
- 阻断说明（存在时优先，其余省略）
- 相分警告（primary 冒充分相结果时才出现）
- 质量指标表：contig_count / contig_n50 / total_bp / busco_* 等
- 污染 / 细胞器候选（仅在存在候选时出现）
- 判定：执行失败不视为通过、指标缺失如实标注不推断通过

## 值标注约定

| 情况 | 输出 |
|---|---|
| 结构化产物缺失该指标 | `未评估/无记录` |
| 该环节工具执行失败 | `执行失败` |
| 该指标不适用 | `不适用` |

任何取数都只能来自 `products` 输入，不得凭空填数。
